NOT DEPLOYED — run locally using docs/setup-guide.md

This is a pure HTML/CSS/JavaScript application with no backend.
To run it locally:

  Option 1 (simplest): Open index.html directly in Chrome or Firefox
  Option 2 (recommended): python -m http.server 8080 → http://localhost:8080
  Option 3: npx serve . → http://localhost:3000

See docs/setup-guide.md for full instructions.
